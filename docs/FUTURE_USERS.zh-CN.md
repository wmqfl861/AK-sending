# 后续其他用户互传

第一版“我的设备”靠明确配对的信任关系，不强制账号。
第二版先实现一次性邀请，再增加联系人和账号。User、Device、TrustGrant 分离，账号不是网络地址或文件通道。
邀请携带短期身份/连接授权，可限时、限次数、撤销；不包含文件正文或内容哈希。
接收方明确接受后，再经认证直连交换任务清单和文件。账号服务故障不破坏已有设备的离线局域网信任。

两端仍需同时在线且系统允许运行。没有任何云端文件保管、离线下载、中继或第三设备代存能力。
网页临时接收、自动同步、多目标任务分别立项；浏览器传输能力不能简单视为原生 QUIC 适配的附带功能。
自动同步若未来立项，需要独立冲突/删除/权限模型，仍遵守 ADR-001。
