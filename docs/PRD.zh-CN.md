# 产品需求基线 v0.1

| ID | 必须实现的需求 | 验收 |
|---|---|---|
| FR-001 | 五端主动发送与接收 | 跨系统 20 个有向组合＋同系统 |
| FR-002 | 可达局域网优先，无外网可运行 | 关闭外网、停止协调服务仍可完成本地任务 |
| FR-003 | 公网只设备直连 | 禁止中继的 NAT/防火墙矩阵 |
| FR-004 | 不压缩、不转码、原始字节 | 原件与接收件摘要相同 |
| FR-005 | 无商业限速 | 代码无收费速度档；吞吐按瓶颈对照 |
| FR-006 | 无应用级大小/类型/总数量额度 | >4 GiB、100 GB 级、10 万文件样本 |
| FR-007 | 默认保存目标和单次改选 | 重启后授权恢复、撤权后可重新选择 |
| FR-008 | 文件夹、空目录、多文件队列 | 结构与文件结果完整，超长扫描可取消 |
| FR-009 | 暂停、重试、断点续传 | 双端重启、切网、后台中断测试 |
| FR-010 | 设备配对、身份核验与信任撤销 | 仿冒设备和撤权请求失败 |
| FR-011 | 真实通道状态与诊断 | 无中继状态；失败不伪报完成 |
| FR-012 | 后续他人互传 | 邀请授权与设备身份分离，不改数据路径 |

## 额度与容量

“无上限”指无产品人为额度，非无限资源。文件系统单文件能力、剩余空间、队列存储和系统选择器限制需给出明确错误。
有限并发、资源背压、恶意请求防护及用户自选网络策略不等于商业限速。
不以扩展名阻止普通文件；对符号链接、设备文件、套接字等特殊文件系统对象单独定义处理，不能静默丢弃后报告全部完成。

## 保存与授权默认值

每次接收默认确认；可信设备自动接收可单独启用，默认关闭。重名默认保留两份。
接收确认窗口默认 120 秒（E2 决定，2026-11-13；原冻结 v1 模型 30 秒）：窗口内同意即传输、到期未决定自动拒绝且零字节落盘，界面显示剩余秒数倒计时；发送端空闲预算相应不低于 150 秒，等待期间连接保持。
默认只在获准网络传输，使用蜂窝数据需授权；网络变化不自动突破原先约束。
任务历史本机保存。清理任务记录、删除临时文件、删除已收到文件是不同操作。
发送端离线等待，不上传云端。源文件必须保持可读、版本稳定。

## 非首版范围

不做自动同步、远程文件浏览、远程删除、云端投递、网页接收或团队管理。
不提供任何中继服务、备用代理节点、广告/收费限速方案。
公开发行前另行决定品牌素材、许可和隐私政策；没有代替用户完成商店账号注册或采购。
