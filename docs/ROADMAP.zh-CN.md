# 开发路线与完成定义

## 当前位置（2026-11-03）

按 [ADR-002](adr/002-protocol-stack-and-order.zh-CN.md) D5 顺序，"局域网 Rust 命令行原型"与"公网直连探测工具"两步已按单机可执行范围完成：11 个 crate、workspace 417 项测试（＋sqlite 特性 26 项）全绿、clippy 双配置零警告；验证均为环回 L2 形态（单机、QUIC 环回/本机网卡、真实文件系统），详见 [开发总结](../reports/DEV_SUMMARY.zh-CN.md) 与 [开发验证记录](../reports/dev-validation-2026-11-02.txt)。P0 门槛中的真机、跨网段/真实 NAT、公网穿透实测部分仍开放（BACKLOG P0-01/02/05/06/07 未执行项）；本地可执行范围已尽，余项需第二台机器、真实网络、Flutter SDK 与移动工具链等外部资源。下方原始工期表保持不变，仅作工作量参考。

不将文档齐全或原型代码存在计作 P0 通过；下列工期是 3–4 名全职成员的原始工作量参考，需据实重估，不是自动执行承诺。

顺序工作量约 18–25 周，含缓冲五端稳定版约 20–28 周；单人＋AI 不直接套用该估算。
删除中继部署/费用规划，新增对纯直连成功/失败覆盖、服务边界和隐式回退的验证，不因此承诺更短工期。
P0 就做 iOS，P3 只是补齐完整产品化。真实系统支持矩阵与网络验证结果优先于估算。

## 首个业务里程碑

关闭外网的同一路由网络，Windows↔Android 安全配对、选目录、>4 GiB 文件、断网/恢复、最终摘要一致；同期 iPhone 运行最小收发及授权/后台实验。

## 人员责任

网络/核心一人；Flutter/交互一人；移动与桌面原生适配一人；测试发布由第四人或明确分工兼任。
每阶段都有代码审查、实际测试、已知限制和交接。不得用未运行的测试脚本或占位目录标记完成。
