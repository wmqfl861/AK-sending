# 验收计划 v0.2

依据：[蓝图](BLUEPRINT.zh-CN.md)、[路线](ROADMAP.zh-CN.md)、[ADR-001](adr/001-direct-only.zh-CN.md)。下列是未来验收要求，不是当前测试结果。

## 证据等级

L0：文档/配置/依赖静态检查。L1：领域逻辑和协议单元测试。L2：真实进程、socket、磁盘和故障注入。L3：多设备、五平台、跨运营商、后台与发布验证。
必须记录基线/提交、工具链、目标平台、执行命令、退出码、测试规模和日志位置。依赖官方文档、其他人的统计和已编写测试不能计作项目通过。

## 强制测试矩阵

| ID | 测试 | 判定 |
|---|---|---|
| T01 | 路由器断外网，关闭协调服务，再启动已配对客户端 | 可发现或用离线地址补充并完成传输，不暗访公网 |
| T02 | LAN 和公网均可达，公网候选先完成准备 | 数据仍优先真实本地通路，不能仅因公网先握手而锁定公网 |
| T03 | 真实 IPv6/IPv4 公网、不同 NAT、热点、公司受限网络 | 分别记录完整连接、打洞、持续传输结果；失败明确等待，无 relay |
| T04 | 保留信令和 STUN，阻断双方全部已选直连数据路径 | 接收方可靠保存进度在允许的在途缓冲排空后停止；不得经信令或隐藏通道继续增长 |
| T05 | 稳定直连后停止协调服务器 | 稳定数据路径继续；网络变更需要协调时等待，不上传文件 |
| T06 | 注入 relay/未知路径、伪造对端、过期授权、候选重放 | 文件引擎拒绝；已有连接 epoch 失效后暂停并重新验证 |
| T07 | 对协调接口发送未知字段、文件 blob、TURN 消息、超大帧 | 按协议拒绝，无通用转发、上传、下载或动态代理入口 |
| T08 | 相同时间和候选规模下传 10 MiB 与 1 GiB，并抓取三端流量 | 服务端只有控制流量；不能只靠搜索明文证明没有密文中继；检查接口与连接端点 |
| T09 | 0 字节、边界块、>4 GiB、100 GB 桌面样本 | 与选定源字节摘要一致；空文件与整数溢出处理正确 |
| T10 | 多文件、目录/空目录、十万小文件样本 | 顺序与内容正确；内存由活动窗口决定，不把整个队列展开成常驻对象 |
| T11 | 在写块前后、同步前后、数据库提交前后、重命名前后杀进程 | 恢复核验实际磁盘与记录；不误报完成，不保留无依据的可靠进度 |
| T12 | 截断/篡改临时文件、数据库范围不一致、源文件变化 | 重校验/回滚/提示；不复用错误块，不拼接出混合版本后报告成功 |
| T13 | 最后完成消息丢失、重复恢复请求和重复 chunk | 幂等，最终文件不重复，发送进度不替代接收落盘确认 |
| T14 | 磁盘满、目录删除/撤权、提供器无随机写/原子重命名 | 明确可恢复状态；额外暂存前检查空间，不最后一步才无提示失败 |
| T15 | 路径逃逸、绝对路径、符号链接竞态、重名/大小写/Unicode/保留名 | 不越出授权目录、不覆盖未授权对象；改名映射可查 |
| T16 | Android 无公网 Wi-Fi，同时蜂窝可用或关闭 | UIDT/适用机制不因示例 INTERNET 约束错误等待；数据不偷走蜂窝，socket 正确绑定 |
| T17 | Android 权限变化、锁屏、任务停止；iOS 前后台、取消、强退、内存压力 | 有准确状态和断点恢复；不以持续后台任务宣传永久接收 |
| T18 | 原图、原视频、HEVC/HDR、多资源照片 | 导入没有取缩略图或转码；最终选定资源逐字节一致 |
| T19 | 五端 20 个有向跨平台组合及同平台、升级数据库 | 每组合有真实记录；未测版本不能标为支持 |
| T20 | 端口映射默认关闭、启用、到期、异常退出 | 未同意时不请求映射；限定本机端口/租约，关闭不改总防火墙 |

T04 停止的是接收端最终可确认的数据推进，不要求丢弃断路前已在接收端缓存的合法数据；测试需记录上界和缓冲排空时间。T08 必须控制持续时间、重试次数和候选规模，避免把心跳或重连流量误判成中继。抓包包含密文，接口/架构/依赖证据共同建立结论。

## 轻量与性能

蓝图第 7 节是统一预算表，避免重复维护。记录 release 单架构下载包、安装占用、桌面进程树 RSS、Android PSS、iOS physical footprint、传输缓存与窗口、文件句柄、SQLite 缓存和任务列表开销。
固定参考设备/网络/电量/温度，十次冷启动取 P95，空闲十分钟取 CPU 均值，分别记录首次发现、重连与任务取消后的资源释放。旧依赖与新依赖对比必须保持构建模式和测量口径一致。
大文件吞吐与同机同网络的认证 QUIC 基线、源盘读取+摘要、目标写入+同步分别对照；初期优化目标为测得最小瓶颈有效速率的 80%，不是固定 MB/s 或所有网络必达承诺。小文件独立记录文件/秒和提供器调用成本。

## 真实公网覆盖

优先覆盖家宽↔家宽、家宽↔蜂窝、蜂窝↔蜂窝、双重 NAT、IPv6 受限/可达、AP 隔离、UDP 被阻断、多网卡/VPN。候选工具每次输出阶段与原因，脱敏保存。
首轮争取至少 30 个不同有向网络组合，报告独立网络数、尝试数、日期与置信度限制；重复同一组合不能虚增样本多样性。受控可达/拒绝场景要求全部符合预期；真实公网成功率不能事先填成论文数字。

## 发布门槛

错误身份接收、路径逃逸、服务器文件回退、内容损坏或错误完成状态属于阻断发布的问题。无资源基线或未完成五端矩阵不能称为五端稳定版。文档定稿、单机模拟和源码存在均不替代这些门槛。
