# 用户体验与界面行为

设备：已配对设备、在线/可达状态、添加/撤销、名称编辑。在线不等于可直连。
发送：设备→普通文件/文件夹/相册原件→确认→接收授权。扫描可取消，边扫描边反馈。
接收：显示可信发送设备、任务规模、目标位置、空间状态和重名规则。默认确认，逐设备可启用自动接收。
任务：扫描/等待授权/连接/传输/暂停/等待设备/校验/保存/完成/失败/取消。
设置：默认保存位置、每次询问、可信自动接收、仅局域网、蜂窝网络授权、托盘/通知与日志管理。

通道显示只有“局域网直连”“互联网直连”“等待直连”。不提供中继开关，也不提供“加速服务器”入口。
公网直连失败：明确写“当前网络无法建立设备直连，文件没有上传到服务器”，提供重试及网络检查说明。
网络从 Wi-Fi 切到蜂窝时遵守已授权策略；不因用户曾允许局域网而默认允许移动数据。
校验/最终保存未完成时不能显示接收成功；多文件任务区分全部成功、部分成功、失败和取消，保留逐文件结果。
历史记录与文件本体分别管理；取消任务清理临时文件的策略明确，不误删已完成文件。
