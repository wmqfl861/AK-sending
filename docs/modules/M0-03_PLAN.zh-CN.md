## 2. 目标与非目标

目标：在现有认证连接内部提供单一、有界、版本化的双向流协议；仅本机授权后打开接收正文入口。提供有界内存 batch 的实验接口，证明未来文件引擎的接入点，但不处理磁盘、文件路径或持久化。保留原核心与传输负例。

非目标：完整文件传输产品、文件清单/保存回执、磁盘撤销栅栏、配对持久化/UI、NAT、发现、自动选路、后台保活。内存 batch 的确认仅指本协议收到并校验该帧，不代表磁盘可靠保存；未来文件 I/O 必须另设不可绕过的写入/撤销/提交边界。已返回的内存数据不是持续有效的写文件许可。

## 3. 协议和 API

- 协议放入 ak-transport 独立内部模块，保持 ak-core 零第三方依赖，不升级依赖。
- 固定头包含 magic、版本、类型、保留位、u64 序号、16 字节 task、32 字节连接绑定、u32 长度；网络字节序。固定头先验证，正文单帧上限 16 KiB；不将帧上限当文件总量额度。
- 连接绑定使用 quinn 标准 TLS exporter 与协议标签、task 上下文，不自制密码算法，不记录 exporter、证书或真实地址。重连获得新绑定，旧帧不复用。
- 一个连接仅拥有一个控制会话，消耗原认证包装；裸 QUIC 连接/流不向 crate 外公开。
- Hello → 本机 ConsentRequest/approve → Ready → 有序 Data/Ack → End/EndAck；未知版本/类型/保留位、错误 task/binding、重放/乱序、超长/截断和非法状态均拒绝并关闭。EndAck 不是保存完成。
- 接收方从网络读 Hello 不代表批准。Ready 及每次接收都检查本地 ReceiveGrant；跨会话/连接、过期、暂停、撤销或取消后的旧许可拒绝。
- 所有 await 都有总时限；已 poll 的操作被外部 timeout/drop 取消、部分写入/读帧失败时 RAII 关闭整条会话，不能接着解析残帧。未 poll future 无副作用。
- 增加仅能关闭当前连接的 cloneable abort handle，使本机 UI 在接收 future 挂起时中止等待；它不能产生许可、改变身份或重开连接。
- 顺序号 checked_add，拒绝溢出；单一在途 batch/backpressure，不建立无界队列。单帧至多一个定长头和一个有界 Vec，不预分配文件总长度。

## 6. 风险、证据与回退

TLS exporter 只绑定密码学连接，不证明 LAN 拓扑；同机测试不证明真实双机/公网。不在本模块宣称异步磁盘撤销线性化或可靠保存，协议批确认与文件提交分离。网络缓冲可能在批准前收到攻击者数据，但应用不交付正文、不触发任何文件写入，QUIC 窗口仍有界。
