# M0-05：最小 Flutter 与移动风险实验壳 — 先行计划

日期：2026-11-02。状态PLANNED。基线 `6ba736588a08705149cde56a2ab2fcf32f54b057`；M0-04原生实验正在跨平台CI/独立审核，阻断必须继承修复后才能验收本模块。先提交本计划，再实施；草稿叠加，不合并。

## 1. 目标与非目标

补 M0 的固定 Flutter 构建、标量FFI调用、手机目录授权和生命周期风险入口。不制作完整文件传输GUI，不引入M1文件引擎/续传/NAT/后台常驻。只有明确按钮启动合成本机探针；界面持续标注“同机实验，不是文件传输或真机验收”。不读取用户现有文件。

M0-04 native API保持不变；Dart只传句柄/整数与低频状态，不搬运正文。移动目录实验是与传输协议隔离的最小授权测试：用户明确选择目录并确认后，只创建唯一新命名的固定小测试文件，读取自己刚创建的数据并删除，不遍历目录、不覆盖现有文件。用户目录URI/bookmark仅本机持久化，不写日志/仓库/证据。

## 2. 构建和接口

- 固定Flutter3.47.0完整commit与engine，读取config/toolchains.json核验；不声称最新版本。平台工程由该精确SDK的flutter create派生，生成器及所有覆盖源码提交，生成工程/摘要随CI保存。生成工程不是已提交源码，报告区分来源。
- Dart依赖仅Flutter/测试SDK，先通过只读候选流程生成真实pubspec.lock，再原样提交；正式验证使用锁文件约束，不把候选成功当验收。固定生成的Android AGP/Gradle/Kotlin兼容组合并记录，不静默升级。
- Linux/Windows打包native动态库；Apple静态链接并保留5个C ABI导出；Android arm64打包16KiB对齐so。五端release构建，iOS不使用生产签名、只无签名链接；无发布/安装授权扩张。
- FFI版本不符或库缺失明确错误；单任务、5Hz聚合状态；取消后继续有界检查release，不能把状态cancelled误当线程已退出。生命周期离开resumed时取消，返回前台不自动重启。热重启、进程终止、卸载需要真机验证，不伪造回调。
- Android37显式声明/请求ACCESS_LOCAL_NETWORK，拒绝不自动重试/降级；API26最低目标。loopback不等于真实LAN权限已测。使用系统SAF树选择和持久URI授权，保存/重启后重新核对有效权限；撤销/无效provider失败关闭。
- iOS使用系统目录选择、安全作用域URL和bookmark；访问成对start/stop，通过NSFileCoordinator协调自己的小文件操作；失效/过期bookmark要求重新选择。iOS本地网络权限由真实LAN使用触发，实验壳不能将loopback成功伪称已获LAN权限。
- 平台通道只返回短状态码，不返回真实路径/文件名/系统异常全文。文档说明云文件提供者不等于离线本地目录；测试无公网时应选择本机目录。

A2：三桌面通过Dart FFI实际加载原生库并完成合成TLS探针；组件测试中的fake明确只验证UI，不冒充网络。
A3：五端release工程实际编译/链接和打包native，记录准确工具链/命令/产物摘要/大小；Android查看APK native条目，Apple检查最终二进制导出。构建不代表安装运行。
A4：平台目录代码实际编译；设备实验清单覆盖选择/拒绝/重启复用/撤权/进程终止/失败清理。没有物理设备时这些实测项保持BLOCKED，未测值null，不用静态检查替代。
A5：固定输入、只读CI、源码与已提交lock无修改；生成工程保留来源摘要，候选与正式验证分开；所有失败轮次保留。
A6：真实独立审核、修复复测，最终代码SHA与测试/审核一致。关键构建失败或阻断未解决则PARTIAL。
