# M0-06 先行范围补充：端点收尾

基于计划4bf8fa66b9。在独立进程实验开发时，实施者复核发现：正常会话结束后立即退出Tokio runtime可能丢失QUIC关闭报文；固定sleep只能概率缓解，不能作为正确收尾机制。

在修改生产代码之前补充范围：允许在现有DirectEndpoint上增加消耗自身的`shutdown()`，先关闭端点，再在现有5秒上限内await quinn Endpoint::wait_idle。不暴露裸QUIC对象、不改变TLS、权限、选路或依赖。文档明确它关闭该端点全部连接，不是文件完成回执；取消该等待时端点已经被关闭，不能复用。

验收新增：空闲端点shutdown、已有认证连接shutdown后对端观察关闭；独立LAN成功路径调用该接口后才结束线程。旧108项Rust保留，新增用例另计。错误路径继续失败关闭，不在异常处理中无限等待。先提交此补充再改代码；审核须覆盖新增边界，不把固定sleep当最终修复。
