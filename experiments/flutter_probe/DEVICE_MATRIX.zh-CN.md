# M0 设备验收矩阵

当前状态：**BLOCKED / NOT_RUN：本会话没有接入物理 Android/iOS/双机 LAN 设备**。任何 CI 编译、链接、模拟器或本机回环成功都不改变这些格子的状态。

| 项目 | Android最低/当前目标 | iOS最低/当前目标 | 必要原始证据 |
|---|---|---|---|
| 安装与冷启动 | NOT_RUN | NOT_RUN | 构建SHA、设备/OS、安装产物摘要、10次冷启动时间 |
| 局域网权限允许/拒绝/撤销 | NOT_RUN | NOT_RUN | 系统设置与短状态码；真实LAN端点实验，不以loopback代替 |
| 目录选择/取消/读写/删除 | NOT_RUN | NOT_RUN | 只选本机测试目录，64字节新文件校验与清理结果 |
| 重启后持久授权、撤权失败关闭 | NOT_RUN | NOT_RUN | 进程冷启动后复用/拒绝；不记录目录位置 |
| 云提供者离线/超时/清理失败 | NOT_RUN | NOT_RUN | 提供者类别、错误状态、无无界重试/任务 |
| 前后台/锁屏/系统杀进程 | NOT_RUN | NOT_RUN | 原生取消与release、恢复不自动启动、临时文件检查 |
| 两设备、无公网但有Wi-Fi | NOT_RUN | NOT_RUN | 独立LAN端点驱动尚需接入；本壳loopback不能执行此验收 |
| 空闲CPU/内存/包体预算 | NOT_RUN | NOT_RUN | release产物、平台正确内存指标、10分钟空闲采样 |

目标版本为Android API26与37、iOS15与26；必须确认可用硬件与目标兼容性，不能把CI主机版本当最低平台测试。桌面Windows11/Ubuntu24.04/macOS13最低目标也须物理或明确标识的虚拟机证据。当前同机实验不覆盖移动真实端点之间的Wi-Fi交互；后续设备接入应另立小模块先行计划，不偷偷把验收改为loopback。

退出准则：所有必需项目有精确SHA的成功证据，或按照项目规则由人明确处置其风险后，才可修改M0总状态。缺证据不能标PASS。对可复现失败记录步骤/状态码/环境，不上传个人目录、地址或身份资料。
