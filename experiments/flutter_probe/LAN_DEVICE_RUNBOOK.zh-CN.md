# M0 双设备实验操作与证据

这是独立端点的合成数据实验，不是文件传输产品。只发送32字节与16KiB两块固定内容，不读取用户文件；不会使用服务器、中继、扫描或端口映射。协议结束不是磁盘保存。

## 构建与两端操作

用当前提交的固定工具链/锁文件执行`scripts/run_flutter_validation.py`；CI产物包含APK或桌面目录归档。Android包使用测试密钥；iOS未签名App须在可信本地Xcode签名安装，不是可直接安装的IPA。签名后产物摘要可能改变，应记录实际安装产物与受测源码关联；不将生产凭据放入仓库。

两台设备连到无访客隔离的同一可信Wi-Fi或有线LAN。在系统网络设置读取各自的IPv4，仅输入自己的实际接口地址及一个未占用的1024–65535端口。不要输入0.0.0.0、路由器公网地址或另一端地址；不要求关闭全局防火墙。桌面提示时只按系统流程允许本应用在可信专用网络通信。

进入“双设备局域网实验”，分别准备临时身份；准备不会打开UDP socket。用可信方式在两端交换公开AKL1信息（包含本机地址/公开证书，不能公开上传日志）。选择一端接收、一端发送，固定对端后在**另一台设备屏幕**核对完整64位十六进制SHA-256，再各自勾选确认。先点击接收端监听，看到listening状态后点击发送端启动。实验失败没有服务器回退；3分钟身份时限、60秒等待或单步5秒超时可能要求重新准备与配对。

iOS的system-mediated状态不表示已经授予LAN权限，实际访问时由系统处理。权限弹窗导致inactive/后台会取消本次任务；在系统允许后返回应用，必须显式重新准备和启动。拒绝后不要绕过设置。Android拒绝/忙时不继续。macOS同样遵循本地网络和沙箱规则。

返回上一页、锁屏、切后台会取消。恢复前台不会自动运行。取消后可能短暂releasing；这代表工作线程尚未退出，不允许新任务或卸载库。热重启导致未知native槽忙时需结束整个实验App进程重新进入，不接管旧句柄。

桌面没有Flutter时可运行：

```sh
python scripts/lan_probe.py --library /path/to/libak_m0_probe.so --bind 192.168.1.10 --port 42424 --role receive
```

另一端选择自己的地址与`--role send`，输入对端offer并键入CONFIRM。Windows库名为ak_m0_probe.dll。上面路径/IP仅示例，按实际本机选择。CLI同样只做合成实验。

## 必须执行而尚未由CI证明的实验

断开路由器WAN并关闭两端蜂窝网络，保留Wi-Fi；先确认双方局域网仍连通，再执行上述合成会话。记录设备类型/OS、源码SHA、实际安装产物摘要、角色和短状态码，不记录个人路径/地址/证书。错误证书、拒绝授权、后台、杀进程等分别做负例，不用单次成功替代整个矩阵。

目录实验须另在原页面明确选择本机临时测试目录，测试创建、读取自身64字节、删除、重启复用、撤销权限、提供者离线和清理失败。云文件提供者可能自身联网，不属于本产品文件数据通道；断外网验收选择本机目录。不得把合成LAN成功当作目录持久权限成功。

## 证据包和资源口径

复制`DEVICE_EVIDENCE.template.json`到本机非仓库目录，每个物理Android/iOS目标（minimum/current）单独记录；所有未测项保持NOT_RUN/null。仅把脱敏日志和实际安装构建放入该目录，记录相对路径和SHA-256。

```sh
python scripts/validate_device_evidence.py record.json --root evidence-directory --commit EXACT_40_HEX_SOURCE_SHA
```

退出0仅表示一个记录的字段、必需用例集合和文件哈希一致，**不证明硬件真实性、填表诚实或整个M0通过**。审核者还须检查原始记录、配对设备、实际权限动作、最低系统和全部目标覆盖。模板直接执行必须失败，不能伪造PASS。

Android使用PSS、iOS使用physical footprint，连续10分钟无任务空闲CPU；10次冷启动分别记录，不以单次代替P95。记录安装占用与发布包字节，禁止把原生静态库/ZIP体积当手机内存。无任务页面不应持续轮询；活动时200ms聚合更新。预算超标保留原始值和审查取舍，不改成0或删除样本。

Linux namespace/veth、桌面双进程和Flutter fake组件测试分别只是隔离栈、进程和UI证据，不计作真实无线网络或手机权限验收。IPv6、生产配对密钥持久化、用户文件和性能优化属于后续范围，不以本实验IPv4限制冒充最终产品限制。
